
# Mini ClassBuild

Mini ClassBuild هو تطبيق تعليمي مدعوم بالذكاء الاصطناعي، تم تطويره باستخدام Python وStreamlit. يساعد التطبيق المتعلمين على إنشاء مخططات للدورات التعليمية، وتوليد محتوى تفصيلي للدروس، وتقييم مدى فهمهم من خلال اختبارات تفاعلية متعددة الخيارات.

## المميزات

- **توليد مخطط الدورة:** إنشاء مخطط تعليمي من خلال إدخال موضوع الدورة واختيار مستوى الصعوبة وعدد الدروس، من درسين إلى خمسة دروس.
- **توليد محتوى الدروس:** إنشاء مقدمة وأقسام تعليمية وأمثلة وملخص وتمارين مع تلميحات.
- **توليد الاختبارات بالذكاء الاصطناعي:** إنشاء خمسة أسئلة اختيار من متعدد مبنية على محتوى الدرس المحدد.
- **التحقق من صحة الاختبارات:** استخدام Pydantic للتحقق من بنية الأسئلة، ووجود أربعة خيارات لكل سؤال، ومطابقة الإجابة الصحيحة لأحد الخيارات.
- **تصحيح الإجابات محليًا:** تصحيح إجابات الطالب باستخدام Python دون إرسال طلب جديد إلى Groq API.
- **عرض العلامة والتفسيرات:** إظهار علامة من خمس درجات، مع توضيح الإجابات الصحيحة وتفسيراتها بعد التسليم.
- **إعادة الاختبار:** السماح للمتعلم بإعادة الاختبار نفسه مع الاحتفاظ بالأسئلة ومسح بيانات المحاولة السابقة.
- **إدارة حالة التطبيق:** استخدام Streamlit Session State لإدارة الدورات والدروس والاختبارات والنتائج خلال جلسة الاستخدام.

## المتطلبات

- Python 3.10 أو إصدار أحدث.
- مفتاح API صالح لخدمة Groq.
- اتصال بالإنترنت للتواصل مع Groq API.

## التثبيت

1. افتح Terminal داخل مجلد المشروع.

2. أنشئ بيئة افتراضية:

   ```bash
   python -m venv .venv
   ```

3. فعّل البيئة الافتراضية.

   على macOS أو Linux:

   ```bash
   source .venv/bin/activate
   ```

   على Windows:

   ```bash
   .venv\Scripts\activate
   ```

4. ثبّت المكتبات المطلوبة:

   ```bash
   pip install -r requirements.txt
   ```

5. أنشئ ملفًا باسم `.env` في المجلد الرئيسي، وأضف بيانات Groq:

   ```env
   GROQ_API_KEY=your_groq_api_key
   GROQ_MODEL=openai/gpt-oss-20b
   ```

   استبدل القيمة التوضيحية بمفتاح API الخاص بك. حافظ على سرية الملف ولا ترفعه إلى GitHub.

## طريقة الاستخدام

شغّل التطبيق من المجلد الرئيسي:

```bash
python -m streamlit run app.py
```

ثم اتبع الخطوات التالية:

1. أدخل موضوع الدورة، مثل `Python Programming for Beginners`.
2. اختر مستوى الصعوبة.
3. حدد عدد الدروس.
4. اضغط **Generate Course Outline** لإنشاء مخطط الدورة.
5. اختر درسًا واضغط **Generate Lesson Content** لتوليد محتواه.
6. أنشئ اختبارًا للدرس المحدد.
7. أجب عن الأسئلة الخمسة وسلّم إجاباتك.
8. راجع العلامة والتفسيرات.
9. اضغط **Retake Quiz** لإعادة الاختبار نفسه.

## آلية تصحيح الاختبارات

يستخدم التطبيق Groq API لتوليد أسئلة الاختبار، بينما تتم عملية التصحيح محليًا باستخدام Python، من خلال مقارنة إجابة الطالب بالإجابة الصحيحة لكل سؤال.

تُمنح درجة واحدة لكل إجابة صحيحة، وتكون العلامة النهائية بين صفر وخمس درجات. تظهر الإجابات الصحيحة والتفسيرات بعد تسليم الاختبار.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `GROQ_API_KEY` | مفتاح API المستخدم للوصول إلى خدمة Groq. |
| `GROQ_MODEL` | معرّف النموذج المستخدم في التوليد بالذكاء الاصطناعي. |

## نطاق المشروع الحالي

يركز الإصدار الحالي على توليد مخططات الدورات، وإنشاء محتوى الدروس، وتوليد الاختبارات متعددة الخيارات، وتصحيح الإجابات محليًا، وإعادة الاختبار.

أما معالجة ملفات PDF، وEmbeddings، وتقنية Retrieval-Augmented Generation (RAG)، ووظائف المحادثة، والتخزين الدائم للبيانات، فهي خارج نطاق الإصدار الحالي ومخصصة لمراحل تطوير لاحقة.
